# Coffee System v5 — VPS

## Быстрый запуск через Docker

1. Установить Docker на VPS.
2. Загрузить эту папку на VPS.
3. Скопировать `.env.example` в `.env`.
4. Выполнить:

```bash
docker compose up -d --build
```

5. Проверить:

```bash
curl http://127.0.0.1:3000/health
```

6. Открыть в браузере:

`http://IP_СЕРВЕРА:3000`

## Данные

Данные хранятся в Docker volume `coffee_data`, поэтому контейнер можно обновлять без удаления данных.

## Важно

Для реального публичного доступа лучше поставить HTTPS через Nginx/Caddy и закрыть прямой порт 3000.
