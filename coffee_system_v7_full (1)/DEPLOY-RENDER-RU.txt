COFFEE SYSTEM v7 — RENDER

1. Создай PostgreSQL database в Render.
2. Скопируй Internal Database URL.
3. В Web Service -> Environment добавь:
   DATABASE_URL = Internal Database URL
   SESSION_SECRET = длинная случайная строка
   ADMIN_USERNAME = admin
   ADMIN_PASSWORD = придумай новый пароль минимум 8 символов
   PUBLIC_URL = адрес твоего Web Service
   NODE_ENV = production
4. Загрузи файлы v7 в ту же Root Directory, из которой сейчас запускается сайт.
5. Dockerfile Path должен оставаться ./Dockerfile.
6. Запусти Deploy latest commit.
7. В логах при успехе будет: Coffee System v7: http://0.0.0.0:PORT
8. Открой сайт, войди владельцем и проверь разделы.
9. QR-меню: раздел "QR и меню".

ВАЖНО: бесплатный Render Postgres подходит для теста, но бесплатная база Render имеет ограниченный срок жизни. Для постоянной реальной кофейни используй постоянную/платную базу и резервные копии.
