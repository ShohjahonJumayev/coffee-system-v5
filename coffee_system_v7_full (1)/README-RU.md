# Coffee System v7

Полная версия системы управления кофейней.

## Что есть в v7

- PostgreSQL вместо `data.json`
- защищенный вход через HttpOnly-cookie
- пароли хранятся в виде scrypt-хеша
- роли: владелец, администратор, кассир
- несколько филиалов
- касса: наличные / карта
- история чеков и состав каждого чека
- товары и категории
- склад по каждому филиалу
- минимальный остаток и предупреждения
- рецепты и автоматическое списание со склада
- расходы и изъятия из кассы
- отчеты: сегодня / неделя / месяц / 30 дней
- топ товаров и продажи по дням
- публичное мобильное QR-меню `/menu.html`
- клиент может оформить заказ с телефона
- онлайн-заказы: новый -> принят -> готов -> завершен
- при завершении онлайн-заказа сотрудник выбирает наличные или карту, после чего создается продажа и списывается склад
- QR-код для каждого филиала
- смена пароля
- ручной экспорт операционных данных в JSON (без хешей паролей)
- адаптивный интерфейс для телефона

## Обязательные переменные окружения

Для запуска в Render нужны:

- `DATABASE_URL` — URL PostgreSQL
- `SESSION_SECRET` — длинная случайная строка
- `ADMIN_USERNAME` — первый логин владельца, например `admin`
- `ADMIN_PASSWORD` — первый пароль владельца, минимум 8 символов
- `PUBLIC_URL` — публичный адрес сайта, например `https://coffee-system-v7.onrender.com`
- `NODE_ENV=production`

`PORT` и `HOST` Render передает/использует автоматически. Приложение также имеет безопасные значения по умолчанию для них.

## Первый запуск

При первом подключении к пустой PostgreSQL приложение автоматически:

1. создаст таблицы;
2. создаст филиал `Основной филиал`;
3. создаст владельца из `ADMIN_USERNAME` и `ADMIN_PASSWORD`;
4. добавит несколько тестовых товаров.

После входа рекомендуется сразу изменить пароль в разделе `Настройки`.

## Важно

Это серьезно улучшенная версия, но перед использованием в реальной кофейне все равно нужно провести тестирование на отдельной тестовой базе: продажи, возвраты/ошибочные операции, права сотрудников, печать чеков и резервное копирование базы.

Расчет `Прибыль` в текущем отчете — это продажи минус зарегистрированные расходы из кассы. Это не бухгалтерская чистая прибыль и не учитывает себестоимость автоматически.
