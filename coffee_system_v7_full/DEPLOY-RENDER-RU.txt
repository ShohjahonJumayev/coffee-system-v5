IN COFFEE v11 — SMS-ПОДТВЕРЖДЕНИЕ

1. Замените текущие файлы проекта файлами v11 и сделайте Commit changes.
2. В Render -> Web Service -> Environment добавьте:
   ESKIZ_EMAIL = email аккаунта Eskiz
   ESKIZ_PASSWORD = пароль/API-секрет Eskiz
   ESKIZ_FROM = 4546
3. Save changes / Deploy latest commit.
4. В Eskiz должен быть активный аккаунт и возможность отправки SMS.
5. Старые клиенты v10 после первого входа увидят подтверждение номера по SMS.
6. Номер в заказе всегда берётся из подтверждённого аккаунта.

Остальные переменные (DATABASE_URL, SESSION_SECRET, ADMIN_PASSWORD, Payme, Yandex Maps) не меняйте.
