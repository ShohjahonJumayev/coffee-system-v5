# In coffee v13 — перевод на карту + проверка чека

## Что нового
- Клиент может выбрать «Перевод на карту».
- Сайт показывает номер карты и получателя из Render Environment.
- Для такого заказа чек обязателен: JPG, PNG или WEBP, максимум 3 МБ.
- Чек хранится в PostgreSQL и не пропадает после перезапуска Render.
- В админке заказ получает статус «Чек на проверке».
- Владелец/администратор открывает чек и нажимает «Подтвердить оплату» или «Отклонить чек».
- Пока чек не подтверждён, заказ нельзя принять или отметить готовым.
- После подтверждения заказ считается оплаченным.
- В обычный JSON-экспорт изображение чека не включается.

## Render Environment
Добавьте:
- CARD_TRANSFER_NUMBER — номер карты для перевода
- CARD_TRANSFER_HOLDER — имя владельца карты

Telegram-подтверждение номера из v12 продолжает работать:
- TELEGRAM_BOT_TOKEN
- TELEGRAM_BOT_USERNAME

## Важно
Чек — только подтверждение от клиента. Перед нажатием «Подтвердить оплату» обязательно проверьте реальное поступление денег в банковском приложении.


## v13.1 — только предоплата для онлайн-заказов
В клиентском разделе онлайн-заказа убрана оплата при получении. Доступен только перевод на карту с обязательной загрузкой чека. Наличные в кассе для сотрудников не отключены.

## XPrinter / печать
- В «Настройки» выберите 58 мм или 80 мм.
- Установите Windows-драйвер XPrinter и подключите принтер к компьютеру.
- Чек можно печатать после продажи или из раздела «Чеки».
- Отчёт смены можно печатать при закрытии кассы или из «Истории смен».
- В окне печати Windows выберите установленный XPrinter и правильный размер бумаги.
