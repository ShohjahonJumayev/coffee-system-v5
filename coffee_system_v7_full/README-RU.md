# In coffee v11

Новое:
- регистрация клиента завершается только после 6-значного SMS-кода;
- номер телефона нельзя подменить при оформлении заказа — он берётся из подтверждённого аккаунта;
- заказ (включая наличные при получении) доступен только для подтверждённого номера;
- старые аккаунты из v10 после обновления должны один раз подтвердить телефон;
- код действует 5 минут, максимум 5 попыток;
- повторная отправка не чаще 1 раза в минуту, максимум 5 SMS на номер в час;
- SMS-код хранится в базе только в виде HMAC-хэша;
- используется Eskiz SMS Gateway;
- сохранены Payme, Яндекс Карта, доставка, фото товаров, QR и история заказов.

Для SMS в Render Environment добавьте:
- ESKIZ_EMAIL
- ESKIZ_PASSWORD
- ESKIZ_FROM=4546 (либо одобренное имя отправителя)

Без этих переменных сайт продолжит работать, но новые клиенты не смогут завершить регистрацию и неподтверждённые аккаунты не смогут оформлять заказы.
