# In coffee v12 — бесплатное подтверждение номера через Telegram

## Что изменилось
- SMS/Eskiz больше не нужен.
- Регистрация подтверждается через Telegram Bot.
- Клиент открывает бота по одноразовой ссылке и нажимает «Поделиться моим номером».
- Сервер принимает только контакт, принадлежащий тому же Telegram-пользователю.
- Номер Telegram должен совпасть с номером, введённым на сайте.
- Без подтверждения нельзя оформить заказ, в том числе с оплатой при получении.
- Старые аккаунты с неподтверждённым номером подтверждаются тем же способом.

## Render Environment
Добавьте:
- TELEGRAM_BOT_TOKEN — токен от @BotFather
- TELEGRAM_BOT_USERNAME — username бота без @

PUBLIC_URL уже должен указывать на адрес сайта. При запуске v12 сервер сам настраивает webhook Telegram.

## Безопасность
Токен бота не храните в GitHub и не отправляйте в чат. Храните только в Render Environment.
